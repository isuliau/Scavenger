# Scavenger

This game is about surviving in an island, move with wasd or with keys, farm trees and open your inventory with escape, currently just a proof of concept but will work on it in future weeks.

# Making the game:

It was really fun to make, I made it specifically because I loved to play forager for the first time and I wanted others to experience a game similar to it for free. I have learnt a lot from the past weeks and im very happy of what im able to achieve, im usiing functions way better than before and I use them more as the tool they're meant to be rather than just "make the code shorter lol" (even if ultimately it is possible to substitute functions, it's way more comfortable to use functions). Anyways, hope you enjoy my game even if its barren right now! 

# How to play:

launch up the itch.io page at https://isuliau.itch.io/scavenger, should work for any device that can use html but it was tested on a windows computer, press the play button and fullscreen to start playing!


# Controls:

move with wasd or arrow keys, use the mouse to control the cursor around your character and the open the menu by pressing on the icon or the key detailed in the icon!
